# Memory Game
This repository provides a solution to the exercise on React Practice which is to build a Memory Game using React. The game displays 12 cards face-down (6 pairs) and challenges the user to find all matching pairs by flipping cards two at a time.

Users should be able to:

- flip cards to reveal the image underneath
- match pairs of cards to keep them face-up permanently
- see non-matching cards flip back after one second

Exercise: [https://reactpractice.dev/exercise/memory-game/]
